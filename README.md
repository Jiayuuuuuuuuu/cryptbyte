🚀 **AI Trading System**  
📌 **Overview**  
This AI Trading System is designed to predict market movements using advanced machine learning techniques, whale transaction tracking, sentiment analysis, and a gamification system. Built for the V HACK 2025 competition, it aims to provide real-time trading insights for both beginners and professional traders.  

🔥 **Features**  
- **AI Trading Model**: Uses Hybrid (HMM + CNN + Reinforcement Learning) for multi-timescale trading.  
- **Whale Tracking**: Monitors large transactions to identify smart money movements.  
- **Sentiment Analysis**: Analyzes market sentiment from Twitter, Reddit, and news.  
- **Real-time Trading Dashboard**: Interactive UI with live market trends.  
- **Gamification System**: Users earn tokens for trading and can redeem rewards.  

🛠️ **Tech Stack**  
🚀 **Backend**  
- Python (Flask/FastAPI)  
- Machine Learning: TensorFlow, PyTorch, Scikit-learn  
- Database: PostgreSQL, Firebase, MongoDB  
- APIs Used: CryptoQuant, Glassnode, Coinglass, Whale Alert  

🎨 **Frontend**  
- React.js  
- TailwindCSS  
- Chart.js (Data Visualization)
